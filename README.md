# PanoFolio

PanoFolio is an AI-first platform for creating, managing, and sharing immersive 360° virtual tour portfolios with a modern creator dashboard and scalable architecture.

## Development approach

PanoFolio follows a documentation-first workflow. Every feature is discussed, designed, documented, reviewed, and approved before implementation. The Product Bible is the single source of truth for developers and AI assistants.

## Repository structure

- `.ai/` — AI collaboration rules and workflows
- `docs/` — Product Bible and technical specifications
- `frontend/` — public portfolio and dashboard application
- `backend/` — API and platform services
- `mobile/` — reserved for future mobile applications

## Current status

The product foundation is approved. Detailed screen specifications are now in progress, beginning with the public portfolio experience.
